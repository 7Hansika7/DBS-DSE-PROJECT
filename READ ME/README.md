## 🛠️ System Highlights

1. **3D WebGL Visualization Engine**:
   - Interactive rotating cybernetic iris with orbiting models (MacBook, AirPods, Keyring, Student ID, Hydro Flask).
   - Real-time responsive canvas with dynamic orbital camera.

2. **5-Vector Neural/Affinity Engine**:
   - Multi-modal scoring balancing Category (30%), Semantic Keywords (25%), Spatial Telemetry (20%), Color Distance (15%), and Temporal Decay (10%).

3. **Zero-Dependency Node Server**:
   - Native HTTP server (`server.js`) delivering ultra-fast JSON persistence and serving the full 3D frontend on `http://localhost:5050`.

4. **Security Vault Protocol**:
   - Manages physical custody of sensitive personal items within designated campus lockers.
